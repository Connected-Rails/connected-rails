# Menu artwork

`menu-background.jpg` is the picture behind the main menu. It is compiled into the binary
(`main.rs`, `MENU_BACKGROUND`) so that the executable needs no asset directory beside it.

**The file currently here is a placeholder and is not ours to distribute.** It stands in
until we have our own render, and it has to be replaced before anything is published.
Nothing but the menu reads it, so replacing it is a file swap — same name, 16:9, and dark
enough on the left that the wordmark and the verbs sit on it without a heavier scrim
(`menu.rs`, `scrim_gradient`).
